# Leveraging-TDC-to-Bound-FDR
This repository contains the code for my research project in the unit SCDL3992 (Science Dalyell Individual Research Project). The project develops a Target–Decoy Competition–based procedure for providing an upper bound on the False Discovery Rate (FDR) under dependent true-null p-values.

## Contents

- `SCDL3992_report.pdf` – Final research report  
- `code/` – R scripts implementing the FDR Bound procedure, evaluation metrics, simulation studies, and dependent p-value generators  
- `reports/` – Simulation outputs, summary tables, and generated plots  

## Methods

- Target–Decoy Competition–based FDR bounding procedure  
- Folding and score-mapping of p-values  
- Simulation studies under independent and dependent p-value structures  
- Comparison with classical FDR procedures (BH, Storey, BY)

## Tools

- R programming  
- Statistical simulation and visualisation libraries
